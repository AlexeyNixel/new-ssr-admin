# Раздел «Комиксы» в админке

## Задача

Реализовать создание и редактирование комиксов в админ-панели — бэкенд
(`GET/POST/PATCH /comics`, `/comics/genres`, `/comics/series`) уже готов и
отдаёт реальные данные (см. отчёт бэкенда `2026-09-15-1300-comics-entity.md`).

## Что сделано

По прямому образцу раздела «Игры» (см. `2026-09-11-games-admin-section.md`) —
структура полностью аналогична, но проще (без миграции, без статусов, без
файла правил, поиск только по названию — полнотекстовый не нужен).

- `services/types/comic.type.ts`, `services/api/comic.api.ts` — типы и
  API-слой. `getAllGenres`/`getAllSeries` — через `getWithoutPagination`
  (эти эндпоинты отдают массив без `{data, meta}`).
- `services/endpoints.ts` — добавлены `comic`, `comicGenre`, `comicSeries`.
- `app/schemas/comic.schema.ts` — zod-схема (обязательно только `title`).
- `app/components/Ui/SelectComicGenre.vue`, `SelectComicSeries.vue` — прямые
  копии `SelectGenre.vue`/`SelectSeries.vue`, переведённые на
  `useComicApi`/`ComicGenre`/`ComicSeries`: мультивыбор (жанры) / одиночный
  выбор (серия) с созданием «на лету».
- `app/components/Ui/UploadImages.vue` — переиспользован как есть (компонент
  уже общий, без правок под комиксы).
- `app/components/Modals/AdminComic.vue` — форма по образцу `AdminGame.vue`/
  `AdminBook.vue`: картинки (до 3), название, сценарист/художник (два разных
  поля), краткое/полное описание (`EditorCustom`), номер тома/год/возрастной
  рейтинг, жанры, серия, ссылка на источник, видимость (`isDeleted`).
- `app/pages/comic/index.vue` — список: обложка, название + бейдж серии
  (`Серия · том N`), автор/художник (объединены, если различаются), статус,
  дата добавления, поиск, пагинация, deep-link `?editId=` через
  `useModalRouteOpener`.
- `app/components/LayoutAside.vue` — пункт меню «Комиксы» (сразу после «Игры»).

Отдельные страницы управления жанрами/сериями комиксов, как и в играх,
сознательно не делал — создание «на лету» из формы уже покрывает запрос.

## Проверка

- `npx nuxt prepare`, `npx tsc --noEmit -p .nuxt/tsconfig.json`, `npx eslint`
  по всем новым/изменённым файлам — чисто (в проекте есть 2 pre-existing
  ошибки, не мои, не трогал).
- **Вживую в браузере** (chrome-devtools, `npm run dev` на :3001, реальный
  бэкенд на :3300): список комиксов — рендерится без ошибок в консоли (только
  уже существующие безобидные предупреждения Nuxt DevTools/Suspense/tiptap,
  не связанные с комиксами). Создание: заполнил название, сценариста,
  художника, номер тома, создал жанр и серию «на лету» прямо из формы —
  отправил, запись появилась в списке (0 → 1), тост «Комикс создан», бейдж
  серии показал «QA Серия · том 2». Редактирование: открыл созданную запись —
  все поля (название, сценарист, художник, номер тома, жанр, серия) корректно
  подтянулись с сервера. Тестовые данные (комикс, серия, жанр, служебный
  QA-пользователь) удалены после проверки через Prisma-скрипт.

## На заметку

- Обложки отдаются через `http://static.infomania.ru${path}` — тот же
  хардкод хоста, что и у книг/игр/клубов.
- Полнотекстовый поиск сознательно не подключён (в отличие от игр/постов) —
  бэкенд ищет только по `title`, по явному запросу пользователя.
