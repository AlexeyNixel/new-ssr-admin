# Поля ticketUrl и isPushkin в админке события

Дата: 2026-11-06 13:40

## Что сделано

### Типы — `services/types/event.type.ts`
Добавлены поля `IEvent`: `ticketUrl?: string | null`, `isPushkin: boolean`.

### Схема валидации — `app/schemas/event.schema.ts`
- `ticketUrl`: пусто — допустимо; иначе строка должна начинаться с `http://` или
  `https://` (сообщение «Ссылка должна начинаться с http:// или https://»);
- `isPushkin`: `z.boolean().default(false)`.

### Форма события — `app/pages/event/admin/[[id]].vue`
- Карточка «Билеты» (иконка `i-lucide-ticket`) под карточкой «Где и для кого»:
  - поле «Ссылка на билет» с подсказкой «Касса: kassir.ru, culture.ru, quicktickets
    и т.п. Нет предпродажи — оставьте поле пустым», тип `url`, плейсхолдер `https://…`;
  - переключатель «Билет по Пушкинской карте» в стиле остальных полей
    (`USwitch`, описание «Событие попадёт на страницу «Пушкинская карта»»).
- При открытии существующего события оба значения приходят из API.
- Копирование (`?copyFrom=`) переносит оба значения вместе с остальными полями.
- При сохранении пустое поле отправляется как `null`.
- Поле добавлено в `fieldLabels` (для баннера несохранённых изменений).

Бэкенд сам добавляет блок «Купить билет» в начало описания при сохранении ссылки
(см. отчёт backend), поэтому в админке ссылку достаточно указать один раз.

## Как проверено

- `npx eslint app/pages/event/admin/[[id]].vue app/schemas/event.schema.ts services/types/event.type.ts` — без ошибок.
- Форма открыта в отдельном Chrome (localhost:3001, профиль `chrome-admin-check`):
  событие с `ticketUrl = https://kassir.ru/test-later` и `isPushkin = true` —
  поле «Ссылка на билет» заполнено, переключатель Пушкинской карты включён.
- Сохранение: переключатель выключен → `PATCH` ушёл, API вернул `isPushkin: false`;
  повторное открытие формы показывает `data-state="unchecked"`.
- Включение обратно + сохранение → в API `isPushkin: true`, после перезагрузки формы
  переключатель в положении `checked`.
- Смена ссылки → `PATCH` сохранил новое значение, повторное открытие показывает его.
- Очистка ссылки → в API `ticketUrl: null`.
- Невалидная ссылка `kassir.ru/no-scheme` → форма не уходит, показывается сообщение
  «…начинаться с http:// или https://».
