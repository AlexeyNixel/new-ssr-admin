# ИИ-обработка текста: сохранение картинок

**Дата:** 2026-10-29
**Проблема:** при генерации текста из статьи пропадали изображения.

## Причина

В `EditorAiPopover.vue` текст для модели собирался через `doc.textBetween()` и
`editor.getText()` — это **только текст**, картинки в него не попадают. Ответ
вставлялся через `setContent(html)` / `insertContentAt(...)`, то есть содержимое
заменялось целиком: всё, чего не было в ответе модели, исчезало.

## Что сделано

### `app/utils/aiImages.ts` (новый)

- `captureAiSource(editor, from, to)` — собирает текст фрагмента и картинки:
  - позиции `<img>` берутся обходом документа (`nodesBetween`/`descendants`),
    HTML — из `editor.getHTML()`, поэтому сохраняются `src`, `alt`, ширина и стили;
  - в тексте каждая картинка заменяется меткой `[[ФОТО 1: подпись]]`
    (подпись — `alt`/`title`), метки встают отдельными строками между абзацами;
  - для каждой картинки запоминается «якорь» — текст перед ней (для возврата,
    если модель потеряет метку).
- `injectAiImages(html, images)` — возвращает картинки в ответ:
  - метка между абзацами → `<img>` блоком;
  - метка внутри `<p>` → абзац разрывается: `</p><img><p>`, пустые `<p>` убираются;
  - потерянная метка → вставка после абзаца с якорем, иначе в конец статьи;
  - дубликаты и метки с неизвестным номером удаляются;
  - терпит варианты `[ФОТО 1]`, `[[ фото 1 ]]`, `[[ФОТО 1: подпись]]`.
- `stripImageMarkers(text)` — текст без меток для режима «Анонс».

### Промпт (`services/ai/prompts.ts`, `server/api/ai/format.post.ts`)

Добавлен `AI_IMAGE_RULES`: сохранить каждую метку ровно один раз, не менять номер
и подпись, поставить её отдельной строкой в тот абзац, к которому фото относится
по смыслу. Правила добавляются к системному промпту только если в тексте есть
метки.

### UI (`app/components/Editor/EditorAiPopover.vue`)

- текст для модели собирается с метками, картинки запоминаются в `scopeImages`;
- предпросмотр и кнопка «Заменить текст» используют ответ **с уже возвращёнными**
  картинками (`previewHtml`), «Копировать» — тоже;
- в модалке появилась строка «Фотографий в тексте: N — сохранятся и встанут по смыслу»;
- при закрытии/смене режима картинки сбрасываются, для «Анонса» метки не отправляются.

## Проверка

- `eslint` — чисто (осталось только старое предупреждение `vue/no-v-html` на предпросмотре).
- `tsc -p .nuxt/tsconfig.server.json` — без ошибок.
- `tsc` для `aiImages.ts` + тест на совместимость с типом `Editor` из `@tiptap/vue-3` — без ошибок.
- Логика вставки прогнана на 11 кейсах (Node, скомпилированный модуль):
  метка между абзацами, метка внутри абзаца, пустые абзацы, возврат по якорю,
  вставка в конец, дубликаты, одиночные/двойные скобки, нижний регистр, лишние
  пробелы, неизвестный номер метки, `stripImageMarkers` — все прошли.
- В браузере не проверялось: `nuxt build`/`dev` в песочнице не запускаются
  (`spawn EPERM`). Проверить локально на новости с фотографиями.

## Ограничения

- Если модель переставит текст так, что якорь не найдётся и метку потеряет,
  фото уйдёт в конец статьи — это осознанный запасной вариант, а не потеря.
- Ширина картинки сохраняется как в оригинале; после вставки её можно поправить
  штатным ресайзом в редакторе.
